## 1. 背景与目标

v2 规格的导出流程要求用户**手工输入服务器绝对路径**,且只能看到单层目录的扁平文件列表。本次需求:像百度云盘一样**层层穿透目录**选择文件:

1. **免路径输入**:连接成功后直接进入可点击导航的文件浏览器,起始目录为登录用户的 home;
2. **目录导航**:文件夹作为一等条目展示,单击进入;面包屑 + 后退/前进;
3. **跨目录多选**:勾选状态按完整路径记录,切换目录不丢失,可跨目录多选打包为一个 zip;
4. **单选/多选下载语义不变**:1 个文件裸导出(沿用冲突三选一)、≥2 个流式 zip(沿用整包作废与 4GB 防护)、"导出并打开"仍限恰好 1 个 `.bag`。

## 4. 桥接协议变更(v3)

`packages/ssh-bridge/src/protocol.ts`、`SshBridge.ts`、`SshSession.ts`、`ssh2Connector.ts` 与客户端 `ServerExportBridgeClient.ts` 同步修改,**不保留 v2 兼容路径**(沿用 Z17 模式)。

```ts
export const PROTOCOL_VERSION = 3;
export type ListEntryKind = "bag" | "active" | "file" | "dir";
```

### 4.1 `connected` 携带 home

```ts
| { type: "connected"; requestId: string; home: string }
```

桥接在 SSH 连接成功后 `sftp.realpath(".")` 解析 home;**realpath 失败兜底 `"/"`**(不阻断连接)。客户端以此作为浏览起始目录(B3)。

### 4.2 `list` 响应携带 canonical 路径

```ts
| { type: "list"; requestId: string; path: string; entries: ListEntry[] }
```

- 桥接收到 `list` 后先对请求路径 `sftp.realpath` 规范化(失败 → 映射错误码,通常为 `NO_SUCH_PATH`),**响应中的 `path` 为 canonical 结果**;面包屑、历史栈、勾选键、visited-dirs 全部使用 canonical 路径(B8);
- 客户端对 `.`/`..`/多余斜杠不做任何本地拼接猜测——导航目标永远由"当前 canonical 路径 + 目录名"构成,canonical 化只在桥接发生;
- canonical 路径同时是 visited-dirs 集合的键(§4.4)。

### 4.3 `list` 组装:目录下发与 symlink 跟随

- **常规文件**:按名字归 `kindForName`(`bag`/`active`/`file`),不变;
- **目录**:`kind: "dir"` 下发;size 字段仍下发 attrs 值,UI 忽略(显示 "—");
- **symlink**(B6):对每条 symlink 执行 `sftp.stat`(跟随;**逐条独立捕获失败**——单条 stat 失败不得使整表失败;并发**限流**(如上限 32),避免大目录下无界并发打满 SFTP 通道):
  - 目标是目录 → `kind: "dir"`;size/mtime 取**目标**值;
  - 目标是常规文件 → 按名字归 kind;size/mtime 取**目标**值(修订 §11.6,进度分母与 4GB 预检随之更准);
  - 目标是 socket/fifo/设备(stat 成功但类型为 special) → **不下发**:此时已确知其不可下载,与直接 special 条目同等处理,不展示注定失败的条目;
  - stat 失败(断链、循环、权限) → **降级**:按链接自身 size/mtime、按名字归 kind 作文件下发——与 v2"未下发类型位按常规文件"的兜底哲学一致(**无法确知时才兜底**),真正不可读时走下载阶段既有失败流程;
- **其他**(socket/fifo/设备):不下发,不变;
- dotfiles 照常全量下发(B10,隐藏是客户端行为)。

`SshSession` 接口新增:

```ts
/** Canonicalize a path (resolves ., .. and symlink components). Throws SshError. */
realpath(path: string): Promise<string>;
/** stat following symlinks; used to classify symlink entries at list time.
 *  跟随语义下 entryType 不会为 "symlink"(循环解析为 stat 失败)。 */
statFollow(path: string): Promise<{ size: number; mtimeMs: number; entryType: SshEntryType }>;
```

### 4.4 `download` 校验:visited-dirs 集合

- 桥接状态从 `#lastListDir: string` 改为 `#listedDirs: Set<string>`(canonical);每次 `list` 成功后加入;**SSH 会话关闭/重连时清空**(集合属于 SSH 会话生命周期);
- `validateDownloadPath(path, listedDirs)`:取 path 的父目录(去掉最后一段;`/x` 的父目录为 `/`),父目录必须在集合内;文件名部分约束——非空、不含 `/`、**非 `.`/`..`**(卫生收紧;v2 前缀模型下此类路径亦不可读,无行为损失)、`kindForName(name) !== "active"`;其余防越权语义不变;
- 同一文件经不同 canonical 路径可达(硬链接、bind mount)→ 各自合法,不去重(§8/§11 记录)。

### 4.5 不变项

`connect`/`ack`/`cancel`/`fileStart`/`fileEnd`/二进制帧/`sshClosed`/错误码表/终止消息恰好一次/取消竞态定序/ack 窗口流控——全部沿用。**逐文件下载消息流与流控记账零改动**(v2 决策 Z1 的收益延续)。

## 5. 跨目录 zip 条目结构(B5)

### 5.1 条目名计算(纯函数,纳入单测)

`zipEntryName(fullPath, commonAncestorDir)`:

- 全部勾选项父目录相同 → 公共祖先即该目录本身,条目名自然退化为**扁平裸名**(LCA 规则的退化情形,非兼容特判;输出与 v2 单目录一致);
- 否则计算所有父目录(canonical,按 `/` 分段)的**最长公共前缀**作为根,条目名 = 相对路径段拼接;
- 公共祖先为 `/` → 条目名 = 去掉前导 `/` 的完整路径(如 `home/u/a.bag`);
- 条目名**永不冲突**:同一 canonical 目录内文件名唯一,相对路径因此唯一;勾选集合按完整路径去重(Set 键),天然排除重复勾选;
- zip 内**不显式写目录条目**(`ZipPassThrough` 名称含 `/` 即可,解压器自动建目录);
- 条目 mtime/UTF-8 名处理沿用 v2 §5.2;条目名净化仍不做(沿用 Z16,相对路径含子目录对 Windows 解压无额外风险)。

### 5.2 其余 zip 语义沿用

命名 `export-YYYYMMDD-HHmmss.zip` + 自动序号、整包作废/清理、4GB 前置禁用(Σ 全部勾选项 list size,跨目录口径)+ 写入时硬护栏、进度按条目文件字节计、`fileStart` 真实 size 修正——全部沿用 v2 §5/§5.6/§7。symlink 目标 size 直接可得(§4.3),预检失真场景减少,护栏仍作兜底。

## 6. UI 变更规格(ServerExport.tsx)

### 6.1 Step A(连接)

- **移除路径输入框**(B3);校验去掉路径规则;连接成功后直接进入 Step B 并自动 list `home`;**首次 list 失败** → 仍进入 Step B:面包屑置于 home、列表区空、Alert 展示错误码文案,可 [刷新] 重试或 [断开并返回](§8);
- localStorage:新增 `foxglove.serverExport.showHidden`(`"1"`/`"0"`,B10);host/port/username 预填沿用;v2 的 `foxglove.serverExport.bagPath` key 不再读写、亦不清理(全新系统,无迁移代码);
- 入口与标题文案沿用 v2("从服务器导出文件")。

### 6.2 Step B(目录浏览器,重写)

**导航区**:后退/前进按钮(历史栈为空/到底时禁用)→ 面包屑(根 `/` 为首段,点击任一段跳转,当前段不可点,深层溢出横向滚动)→ 刷新 → 显示隐藏文件开关 → 断开并返回。

**历史栈**(B9):会话内数组 + 指针;进入新目录 push 并截断 forward 分支;面包屑跳转视为新导航;断线重连后重置为 `[home]`(B13)。

**列表区**:

- **目录行**:文件夹图标 + 名称 + mtime;**无复选框**(B2);**单击整行进入**(B4);size 列显示 "—";
- **文件行**:复选框 + **单击整行切换勾选**(与 B4 对称);BAG chip、`active` 行禁用 + 录制中 tooltip——沿用;
- **可见性统一口径**:条目可见 ⟺ 匹配过滤词 ∧ (非 dotfile ∨ 显示隐藏开关开);**表头全选/全不选/indeterminate 只作用于可见且可勾选(非 dir、非 active)的项**;勾选状态按**完整 canonical 路径**记录,不随过滤/隐藏/导航丢失(B1);
- **排序**(B11):可见目录名称升序(不区分大小写)在前,可见文件 mtime 倒序在后;平级均以名称为次级键(先不区分大小写、再区分大小写),跨刷新顺序稳定;
- **空态三档**(按序判定,取先命中者):① 目录本身无任何条目 → "该目录下没有文件";② 有条目但**全部**因隐藏开关不可见 → "所有条目均为隐藏文件"(提示开关);③ 其余"可见集为空"情形(过滤词无匹配,含过滤与隐藏叠加) → "没有匹配的文件"。

**摘要条**:"已选 N 项·共 X MB"——N/X 覆盖**全部**勾选项(含他目录与当前目录不可见者)。两个可选括注,按固定顺序拼接、可同时出现:

- **跨目录括注**:D = 勾选项的**不同 canonical 父目录**数;D ≥ 2 时显示"(跨 D 个目录)";
- **不可见括注**:F = **当前目录内**因过滤词或隐藏开关而不可见的勾选项数(他目录勾选项**不计入** F——已由跨目录括注披露,二者不重复计数);F ≥ 1 时显示"(含过滤/隐藏外 F 项)";

完整形态示例:"已选 5 项(跨 2 个目录;含过滤/隐藏外 1 项)· 共 120 MB"。

**按钮区**:沿用 v2 口径(统计全部勾选项):N≥2 → [导出为 ZIP(N 个文件)];N=1 → [导出 1 个文件];[导出并打开] = 恰好勾选 1 项且为 `.bag`(**不限所在目录**);4GB 前置禁用沿用(Σ 全部勾选 list size)。

**导航竞态与 loading**:`navigationSeq` 是唯一的竞态仲裁机制——客户端维护自增序号,发起 list 时捕获当前值,响应到达时序号不匹配即丢弃(连点目录/面包屑、刷新与导航叠加、离开 Step B 后迟到的响应,统一由此覆盖)。导航进行中列表区渲染 loading 占位(不渲染行,无从误点);**导航控件(后退/前进/面包屑/刷新/隐藏开关)与 [断开并返回] 保持可用**——慢目录或请求悬挂时用户可改航或断开。注意桥接对 SFTP 操作无请求级超时,唯一兜底是 10 分钟空闲断开(B16):若全禁用控件,一次悬挂的 list 最长可把用户困住 10 分钟;请求级超时列入 §12。

### 6.3 Step C(导出中)

- "当前文件"显示**相对路径**(与 zip 条目名一致,§5.1);单文件模式显示裸名;zip 目标名显示沿用;
- 导出中禁止返回/关闭即取消,沿用。

### 6.4 Step D(汇总)

- 逐文件列出(沿用 v2 决策 Z18),条目以**相对路径**标识(与 zip 条目名一致,即固化的 `entryName`);四组结构、重试按钮语义沿用;
- zip 模式重试 = 整包重跑,沿用 v2 §7(§7.2 降级情形下为重列成功目录的子集);静默重连后须先重列涉及目录(§7.2)。

### 6.5 导出循环改动

- `ExportItem` 身份从 `name` 改为 **`path`(完整 canonical 路径)**,另存 `entryName`(§5.1 计算的 zip 条目名/裸名)用于 zip 条目与汇总显示;`entryName` 在**导出启动时**按完整勾选集合计算一次并固化,重试(含 §7.2 缩减集合)不重算——保证汇总页标识与多次重试产物的条目名稳定一致;
- 下载请求直接发完整路径:`client.download(item.path)`(v2 的 `normalizedBagPath + "/" + name` 拼接删除);
- 单文件模式:本地文件名 = 裸名,冲突三选一沿用原规格 §10;
- "导出并打开"完成动作沿用(`selectSource` 本地文件)。

## 7. 断线与重连语义

### 7.1 browse 步断线(B13 + B16)

`sshClosed`/桥接断开 → 顶部 Alert + [重连];重连成功 → **回到 home**(重新 list),勾选、过滤词、历史栈**全部清空**;桥接侧 visited-dirs 随 SSH 会话消亡自动清空,两端天然一致。浏览停留超 10 分钟触发空闲断开时同此路径(B16 已知代价,§11)。

### 7.2 导出重试的静默重连(不受 B13 影响)

summary 步 [重试失败项] 的静默重连(密码在内存,沿用 v2)成功后、继续下载前,**必须重列所有重试项的父目录**(去重后逐个 `list`),重建桥接 visited-dirs——否则 §4.4 校验拒绝下载。

- **按目录降级**:某父目录重列失败(已删除/权限变更等)→ 该目录下的重试项直接计入失败组(附原始错误码),**不参与本次导出**;其余目录的重试正常继续。zip 模式产物只含重列成功目录的条目——失败在导出启动前即确定并展示于汇总页,不属于 v2 §7 所防的"静默部分包",不触发整包作废;单文件模式同理逐项继续。
- **静默重连本身失败**(桥接不可达/认证失败等)→ 回连接表单报错(此时任何重试都无法进行,与 v2 相同)。
- 重试使用固化的 `entryName`(§6.5),不因集合缩减重算公共祖先。

UI 浏览位置不参与此流程(用户在 summary 步)。

## 8. 边界情况清单(在 v2 §8 基础上新增/修订)

1. 【修订】v2 §8.12(目录不下发)→ 目录为一等条目;空目录 → "该目录下没有文件"。
2. 【新】进入无权限/已删除目录 → list 报错,**停留当前目录**,Alert 提示,勾选与历史不受影响;**失败的导航不压入历史栈**(仅成功导航 push)。
3. 【新】导航竞态:连点目录/面包屑 → 过期 list 响应丢弃(§6.2 navigationSeq);导航中控件保持可用,[断开并返回] 恒可点。
4. 【新】symlink 指向目录 → 可进入(B6);symlink 指向 socket/fifo/设备 → 不下发;symlink 循环/断链/无权限 → stat 失败降级为文件,下载时报错进失败流程。
5. 【新】当前目录被外部删除后点刷新 → list 报错(NO_SUCH_PATH),Alert 提示,列表清空,用户经面包屑离开。
6. 【新】勾选项在下载前被删除/改名 → 下载 `NO_SUCH_PATH`,zip 模式整包作废(沿用 v2 §7),单文件模式进失败组。
7. 【新】跨目录同名文件 → zip 条目相对路径不同,无冲突(§5.1);汇总页以相对路径区分。
8. 【新】公共祖先为 `/` → 条目名含 `home/...` 等前缀(§5.1)。
9. 【新】同一文件经不同 canonical 路径(硬链接/bind mount)重复勾选 → **同一内容被打包多次**(条目名各异,§5.1 唯一性结论不受影响),**不去重**,记录为已知限制(§11)。
10. 【新】realpath(".") 失败(home 不存在/无权限)→ 兜底 `/`(§4.1);home 即 `/` 时面包屑仅根段,正常。
11. 【新】dotfiles 全隐藏 → 空态"所有条目均为隐藏文件";隐藏项不参与全选;已勾选的 dotfile 关闭开关后仍在勾选集合并计入摘要披露(§6.2)。
12. 【新】切换目录 → 过滤词清空(B12);勾选不受影响(B1)。
13. 【新】断线重连 → 回 home、勾选清空(B13);导出重试静默重连 → 自动重列父目录,重列失败按目录降级(§7.2)。
14. 【新】浏览停留 >10 分钟 → 空闲断开(B16),按 §7.1 处理。
15. 【新】大目录(数千条目,含目录条目)→ 全量渲染,不设上限(B14)。
16. 【新】0 字节文件、含空格/中文/`\` 名 → 沿用 v2 §8.9/§8.10;zip 相对路径条目在 Windows 解压行为不变(Z16)。
17. 【新】symlink 目标 size 直接下发(§4.3),4GB 预检与进度分母更准;`fileStart` 修正保留兜底。
18. 【新】symlink-to-dir 的 size 列显示 "—";目录 mtime 取 stat 目标值。
19. 【新】Windows OpenSSH 服务器:协议假设 POSIX 路径语义,沿用现状立场(§11)。
20. 【新】导出中不允许继续浏览(单连接单工,沿用"导出中禁止返回");浏览与下载不并发。
21. 【新】连接成功后首次 list home 失败 → 仍进入 Step B:面包屑置于 home、列表区空、Alert 报错,可 [刷新] 重试或 [断开并返回](§6.1)。

## 9. 测试要求

沿用"桥接协议层必需、zip 纯函数必需、UI 层不强制"(v2 决策 Z19):

**桥接协议层(现有 `packages/ssh-bridge/src/*.test.ts` 扩展):**

- `connected` 携带 `home`;realpath(".") 失败兜底 `/`;
- `list`:请求路径含 `..`/尾斜杠/symlink 组件 → 响应 `path` 为 canonical;目录/symlink-to-dir → `"dir"`;symlink-to-file 按名字归 kind 且 size/mtime 取目标值;symlink 指向 socket/设备 → 不下发;stat 失败(断链/循环)降级为文件;**单条 stat 失败不影响整表**;直接 socket/设备不下发;

- SSH 重连(新会话)后 visited-dirs 清空,旧目录 download 拒绝。

- 公共祖先计算:全部同目录 → 裸名;多目录 → 相对路径;公共祖先 `/`;父目录互为前缀(`/a/b` 与 `/a/bc` 不得误判);
- 带路径条目名的 round-trip(fflate `unzipSync` 验证);
- 既有 Store/abort/命名/护栏单测不受影响,须保持通过。

Step B 新增的跨目录勾选集合、可见性判定、历史栈等纯逻辑,实现时应抽出为不依赖 React 的模块(与 `serverExportZip` 同法);其单测不强制(Z19 沿用),但建议覆盖——本次改动的主要复杂度集中在客户端状态,纯函数化是控制风险的主要手段。

**仍须通过** `yarn lint` 与 `yarn build:packages`。

## 11. 已知限制与风险

1. **symlink stat 开销**(B6):list 时每条 symlink 一次 stat(限流并发,§4.3);含大量 symlink 的目录 list 延迟增加;内部目录规模可控,接受。
2. **重复内容**(§8.9):同一文件经不同 canonical 路径可达时,其内容在 zip 内被打包多次(条目名各异,无命名冲突),不去重。
3. **断线打断浏览**(B13+B16):挑选文件超 10 分钟触发空闲断开,**意外断线(网络闪断)亦同**;重连后回 home、勾选/历史清空——两项保守决策的叠加代价,反馈强烈时走 §12 扩展(保活/延长超时、勾选恢复)。
4. **POSIX 假设**:Windows OpenSSH 服务器路径语义未适配(沿用现状)。
5. **版本不匹配文案方向**:沿用 v2 §11.5——v3 发布须公告 **web 与桥接同步升级**。
6. **面包屑显示 canonical**(B8):经 symlink 进入 `/data` 时显示真实位置(如 `/mnt/data`),与用户点击路径字面不同——为校验严密性接受的取舍。
7. **同目录大小写变体名**(如 `Readme` 与 `readme` 并存):zip 内为两个不同条目,在大小写不敏感的 Windows 文件系统上解压会互相覆盖——Z16 不净化立场的自然延伸(继承自 v2),记录不处理。
